StarTicket
O StarTicket é um site feito para facilitar a busca e a compra de ingressos para shows de música pop. A ideia principal do projeto é reunirmos os principais eventos pop em um só lugar, permitindo que o público encontre rapidamente todas as informações necessárias sobre os próximos shows.

O que o site faz
No StarTicket, o usuário pode:

Ver a lista dos próximos shows de música pop agendados.

Checar detalhes importantes de cada evento, como a data e o horário.

Verificar o local onde o show vai acontecer.

Ler uma breve descrição sobre o evento e o artista.

Disponibiliza a compra do ingresso de forma simples.
